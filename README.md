# WebCatalog: <Каталог мережевого обладнання>
Навчальний проєкт із дисципліни «Веб-технології».
## Тема
Каталог містить комутатори, маршрутизатори й точки доступу з основними характеристиками. Потрібен, щоб швидко порівнювати моделі й добирати обладнання для мережі
## Модель даних
Поля одного запису:
- `name` — модель пристрою
- `vendor` — виробник
- `type` — тип пристрою (комутатор, маршрутизатор, точка доступу)
- `ports` — кількість портів
- `bandwidth` — пропускна здатність, Мбіт/с
