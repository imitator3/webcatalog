Каталог мережевого обладнання

Каталог містить комутатори, маршрутизатори й точки доступу з основними технічними характеристиками. Буде корисним студентам і початківцям, які добирають обладнання для навчальної чи домашньої мережі.

Модель даних

Кожен запис каталогу містить такі поля:

  • name — модель пристрою
  • vendor — виробник
  • type — тип пристрою (комутатор, маршрутизатор, точка доступу)
  • ports — кількість портів
  • bandwidth — пропускна здатність, Мбіт/с
